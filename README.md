## ✨ Features & Three Core Questions Answered

### 1. Who is Pip?
- **Identity:** Pip is a gentle, sweet baby with a smooth round skull face, huge soft eye sockets with cozy glowing amber pinpricks, a tiny crooked smile, and a bedtime nightcap adorned with stars. (Always friendly, never scary or creepy!).
- **Personality:** Curious, sleepy, a little clumsy, easily delighted. Giggles at everything and hates silence.
- **Profession:** Junior Dream Engineer at Midnight Nursery.
- **Tagline:** *“I build the dreams you fall asleep inside.”*
- **Interactive Eye Tracking:** Pip's luminous amber pupils follow visitor mouse and tilt movements via physics clamping.

### 2. What Does Pip Do? (3 Interactive Showcase Projects)
1. **The Lullaby Lab (`Lullaby.exe`):**
   - Interactive music box with turning golden key animation.
   - Generative pentatonic synthesizer using native Web Audio API (zero audio files!).
   - Floating musical note sparkles and audio equalizer meter.
2. **Nightlight Collection (`Nightlights.exe`):**
   - Bedside porcelain lanterns designed for little creatures afraid of the dark.
   - Interactive 4-hue dream glow switcher (Starlight Gold, Berry Blossom, Moonlit Violet, Minty Slumber).
3. **Dream Delivery Routes (`DreamMap.exe`):**
   - Interactive rooftop flight map across Midnight Nursery.
   - Clickable delivery destinations (Bunny Burrows, Cloud 9 Nursery, Little Spook Tower) dispatching sweet dreams.

### 3. What is Pip's Story? (Illuminated Origin Log)
- **Chapter 01 — The Star That Fell Into a Crib:** How Pip arrived in a wicker basket blinking amber pinpricks at the moon.
- **Chapter 02 — A Clumsy First Symphony:** Turning an accidental clatter of nursery toys into the neighborhood's sweetest lullaby.
- **Chapter 03 — The Junior Dream Engineer:** Receiving the bronze engineering badge to craft dreams you can fall asleep inside.

## 🛠️ Tech Stack & Architecture

- **Core:** Vanilla HTML5, CSS3 (3D Claymorphism, custom properties, perspective transforms), Vanilla JavaScript (ES6+).
- **Audio:** Native Web Audio API (sine & triangle wave synthesis, zero external mp3 dependencies).
- **Visuals:** Official haX.baby high-res studio renders (`pip_avatar_cloud.png`, `pip_lullaby_box.png`, `pip_dream_lantern.png`, `pip_portrait.png`).
- **Typography:** Playfair Display (Serif), Fredoka (UI/Accents), DM Mono (Retro Terminal).
- **Zero console errors, 100% accessible, light/dark dream mood switcher.**
